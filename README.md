# Job Search System

Next.js frontend + Python backend + Supabase.

A single application for:
- tracking MNC applications
- preparing role-specific resumes
- tailoring applications to each job
- interview prep
- showcasing ready projects

## Structure

- `frontend/` — Next.js UI
- `backend/` — Python service
- `supabase/` — schema, migrations, types
- `docs/` — plans and notes

## Goals

- end-of-September readiness
- real apply workflow, not auto-blasting
- FashionGallery integration once demo-ready
- clean separation: job-search presents projects, does not own their source repos
